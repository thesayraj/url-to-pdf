# URL to PDF Converter

## Problem
___
Customers review partner websites for compliance.
However, they take 3-4 hours to visit every page of the partner website, download them as PDF, and then merge all the PDFs. 


## Solution
___
We should make it easy for our customers to convert any URL to PDF


## User Flow
___
1. Customer enters URL
2. Below it, sees two sections - pages on the left side, and their respective PDF on the right side
3. Below it, there is a zip file with all the PDFs merged into a single file
4. If there is a video on the page, flag that a video is present on that page
